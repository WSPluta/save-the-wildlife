## Scope

Use for LiveLabs and workshop guidance that teaches people how to fork, provision, build, deploy, and roll back Save The Wildlife on OCI DevOps and OKE.

## Rules

- Keep commands, paths, and screenshots consistent with the current repo.
- Use placeholders and safe guidance for tokens, tenancy details, and secrets.
- If a workflow changes, update every downstream lab step that depends on it.
- Preserve the educational flow: prerequisites, task boundaries, validation, and next-step transitions.

## High-Value Validation

- Check referenced repo paths still exist.
- Check the deployment assets or scripts the lab names still exist.
- Confirm production-flow docs stay consistent with repo automation and deployment directories.
