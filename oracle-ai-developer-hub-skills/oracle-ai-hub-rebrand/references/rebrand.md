## Correct Terminology

- Use: `Oracle AI Database`
- Use only when specifically intended: `Oracle Autonomous Database (ADB)`
- Avoid as primary product names:
  - `Oracle Database 23ai`
  - `Oracle 23ai`
  - `23ai`
  - `26ai`

## Rebrand Workflow

1. Search for legacy terms.
2. Classify results by docs, UI text, comments, manifests, or scripts.
3. Replace only the wording that is actually incorrect.
4. Do not rename APIs, identifiers, ports, or behavior unless separately requested.
5. Re-scan to verify the sweep.

## Safe Change Rules

- Prefer precise replacements.
- Keep version notes secondary, for compatibility only.
- Preserve valid ADB references.
- Avoid mass identifier churn just because branding changed.

## Validation

- Legacy terms are gone where they should be.
- Accurate ADB references remain.
- No functional changes were introduced.
